\begin{frame}[fragile]{2. Store a candidate and its score}
Construction stores a one-gene chromosome and computes its fitness. The property reads the gene; the representation prints a signed value to three decimals.

\begin{lstlisting}
class Individual:

    def __init__(self, gene_list: list[float]) -> None:
        self.gene_list = gene_list
        self.fitness = objective(gene_list[0])

    @property
    def gene(self) -> float:
        return self.gene_list[0]

    def __repr__(self) -> str:
        return f'x={self.gene:+.3f} f={self.fitness:+.3f}'
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{3. Tournament selection}
Sample three candidates with replacement and select the greatest fitness. Repeat for every output slot. The result contains references to existing objects; it does not create new genes.

\begin{lstlisting}
def select_tournament(population: list[Individual], size: int) -> list[Individual]:
    offspring = []
    for _ in range(len(population)):
        candidates = [random.choice(population) for _ in range(size)]
        offspring.append(max(candidates, key=lambda ind: ind.fitness))
    return offspring
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{Project a proposal into the legal interval}
A proposal above 10 becomes 10; one below -10 becomes -10. A legal value is unchanged. Projection is part of the algorithm, not a plotting adjustment.

\begin{lstlisting}
def clamp(gene: float, low: float=GENE_MIN, high: float=GENE_MAX) -> float:
    return max(low, min(high, gene))
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{4. Blend crossover}
Draw $s=(1+2\alpha)u-\alpha$, $u\sim U[0,1)$. Propose $(1-s)a+sb$ and $sa+(1-s)b$; clamp both to the legal domain. One shared draw makes the proposals complementary, not independent.

\begin{lstlisting}
def crossover_blend(gene1: float, gene2: float, alpha: float) -> tuple[float, float]:
    shift = (1 + 2 * alpha) * random.random() - alpha
    child1 = (1 - shift) * gene1 + shift * gene2
    child2 = shift * gene1 + (1 - shift) * gene2
    return (clamp(child1), clamp(child2))

def crossover(parent1: Individual, parent2: Individual) -> tuple[Individual, Individual]:
    g1, g2 = crossover_blend(parent1.gene, parent2.gene, BLEND_ALPHA)
    return (Individual([g1]), Individual([g2]))
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{5. Gaussian mutation}
Add $\varepsilon\sim N(0,\sigma^2)$ and clamp. Sigma controls typical jump size; it is not a maximum distance. In the full algorithm, mutation activates separately with probability 0.1.

\begin{lstlisting}
def mutate_gaussian(gene: float, mu: float, sigma: float) -> float:
    return clamp(gene + random.gauss(mu, sigma))

def mutate(individual: Individual) -> Individual:
    return Individual([mutate_gaussian(individual.gene, MUTATION_MU, MUTATION_SIGMA)])
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{6. The generational update}
Initialize ten candidates; repeat select, cross adjacent pairs, mutate and replace ten times. Crossover probability is 0.8 per pair; mutation probability is 0.1 per individual. No elitism protects the previous best.

\begin{lstlisting}
random.seed(SEED)
population = [create_random() for _ in range(POPULATION_SIZE)]
history = [max(population, key=lambda i: i.fitness).fitness]
for generation in range(1, MAX_GENERATIONS + 1):
    offspring = select_tournament(population, TOURNAMENT_SIZE)
    crossed = []
    for p1, p2 in zip(offspring[::2], offspring[1::2]):
        if random.random() < CROSSOVER_PROBABILITY:
            crossed.extend(crossover(p1, p2))
        else:
            crossed.extend([p1, p2])
    population = [mutate(i) if random.random() < MUTATION_PROBABILITY else i for i in crossed]
    best = max(population, key=lambda i: i.fitness)
    history.append(best.fitness)
    print(f'Generation {generation:2d} | best {best.fitness:+.4f}')
\end{lstlisting}
\end{frame}

\begin{frame}[fragile]{Checks and interpretation}
Check population size, legal gene bounds and agreement between every gene and its cached score. Replaying a seed should reproduce the ordered population and complete history.\\[0.7em]
Counts are exact. Compare unrounded floating-point values across environments with $\mathrm{rtol}=10^{-12}$ and $\mathrm{atol}=10^{-12}$. Investigate different trajectories. Two example seeds are not an estimated success rate.
\end{frame}
